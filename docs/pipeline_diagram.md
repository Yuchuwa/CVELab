```
                     │
                     ↓
┌─────────────────────────────────────────────────────────────────┐
│              Pipeline 1: CVE原子化Pipeline                         │

├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1️⃣ 数据收集阶段                                                 │
│     ┌────────────────────────────────────────┐                 │
│     │ CVEProcessor.process_from_vulnhub()    │                 │
│     │ ├─ VulnHub README获取                  │                 │

│     │ ├─ 环境信息提取                        │                 │

│     └────────────────────────────────────────┘                 │
│                    ↓                                              │

│     ┌────────────────────────────────────────┐                 │

│     │ ├─ MITRE ATT&CK关键词匹配              │                 │
│     │ ├─ 启发式规则分析                      │                 │
│     │ ├─ CVSS向量解析                        │                 │
│     │ └─ 攻击阶段评分 (12个阶段)             │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  3️⃣ 信息丰富化                                                    │
│     ┌────────────────────────────────────────┐                 │
│     │ CVEEnricher.enrich_*()                 │                 │
│     │ ├─ 攻击时间线分析                      │                 │
│     │ ├─ TTP提取                             │                 │
│     │ ├─ IOC识别                             │                 │
│     │ └─ 拓扑适配分析                        │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  4️⃣ 质量验证                                                      │
│     ┌────────────────────────────────────────┐                 │
│     │ CVEAtomicValidator.validate_*()        │                 │
│     │ ├─ 语法完整性检查                      │                 │
│     │ ├─ 逻辑一致性验证                      │                 │
│     │ └─ 质量评分 (0-1)                     │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  📦 输出: 高质量CVE Catalog                                     │
│     • 32个现代CVE (2018+)                                        │
│     • 平均质量分数: 0.96                                         │
│     • 存储位置: data/catalogs/verified/                         │
└────────────────────┬────────────────────────────────────────────┘
                     │
                     ↓
┌─────────────────────────────────────────────────────────────────┐
│              Pipeline 2: 核心环境生成Pipeline                       │
│              📍 位置: src/clab_builder/core/                      │
├─────────────────────────────────────────────────────────────────┤
│                                                                   │
│  1️⃣ 拓扑解析                                                     │
│     ┌────────────────────────────────────────┐                 │
│     │ ContainerLabParser.parse_topology_file()│                │
│     │ ├─ YAML格式解析                        │                 │
│     │ ├─ 节点和链接提取                      │                 │
│     │ ├─ 网络配置分析                        │                 │
│     │ └─ 服务类型识别                        │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  2️⃣ 拓扑生成                                                     │
│     ┌────────────────────────────────────────┐                 │
│     │ TopologyGenerator.generate_topology()  │                 │
│     │ ├─ 网络隔离配置 (4个安全区域)          │                 │
│     │ ├─ Iptables规则生成                    │                 │
│     │ ├─ 路由表配置                          │                 │
│     │ └─ DNS配置                             │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  3️⃣ 网络连通性测试                                                │
│     ┌────────────────────────────────────────┐                 │
│     │ EnhancedConnectivityTester             │                 │
│     │ .run_5_layer_test()                    │                 │
│     │ ├─ Layer 1: ICMP ping (丢包率/RTT)     │                 │
│     │ ├─ Layer 2: TCP/UDP端口连通性          │                 │
│     │ ├─ Layer 3: DNS解析验证                │                 │
│     │ ├─ Layer 4: 路由追踪 (跳数分析)        │                 │
│     │ └─ Layer 5: 性能测试 (iperf3)          │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  4️⃣ CVE准确性验证                                                  │
│     ┌────────────────────────────────────────┐                 │
│     │ CVEAccuracyValidator.validate_*()      │                 │
│     │ ├─ CVE ID有效性检查                    │                 │
│     │ ├─ 版本准确性验证                      │                 │
│     │ ├─ 漏洞存在性确认                      │                 │
│     │ └─ 环境配置正确性                      │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  5️⃣ 环境质量验证                                                  │
│     ┌────────────────────────────────────────┐                 │
│     │ EnvironmentValidator                    │                 │
│     │ .validate_complete_environment()      │                 │
│     │ ├─ 部署状态检查                        │                 │
│     │ ├─ 服务可用性验证                      │                 │
│     │ ├─ 配置一致性检查                      │                 │
│     │ └─ 环境质量评分 (0-100)               │                 │
│     └────────────────────────────────────────┘                 │
│                    ↓                                              │
│  📦 输出: 可部署的训练环境                                         │
│     • ContainerLab YAML配置文件                                  │
│     • 网络连通性报告                                              │
│     • CVE准确性验证结果                                           │
│     • 环境质量评分                                                │
└────────────────────┬────────────────────────────────────────────┘
                     │
                     ↓
┌─────────────────────────────────────────────────────────────────┐
│                    输出层                                         │
├─────────────────────────────────────────────────────────────────┤

│  🎯 环境质量评分                                                  │
└─────────────────────────────────────────────────────────────────┘
```
